# Offer module

Reusable header offer bar and the offers list it shows.

| Panel | Role |
|-------|------|
| **`offer/bar`** | Placeable bar (typically in the header). Shows up to 3 visible `offer/offer` rows. |
| **`offer/offer`** | List item (heading + link). Definition + admin list only — not in `config.json` `panels`. |

Admin: **Shop → Offer → Offers**.

Shop is not used yet. Product-aware / discount offers are a later todo — see [`todo.md`](todo.md).
